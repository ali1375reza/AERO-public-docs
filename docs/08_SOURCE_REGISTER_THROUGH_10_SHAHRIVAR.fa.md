# فهرست منابع برای Backfill تاریخی

منابع خصوصی زیر برای بازسازی تاریخچه تا ۱۰ شهریور استفاده شده‌اند. فایل خام آن‌ها در این مخزن کپی نمی‌شود، چون بعضی از آن‌ها جزئیات سطح پیاده‌سازی دارند.

| خانوادهٔ منبع | پوشش استفاده‌شده در سابقهٔ عمومی |
|---|---|
| پروندهٔ انگلیسی از روز صفر تا زمان تهیه | منشأ، AERO-LAB، FAST_ROTATION_50، ATOMIC_HUNTER_50، خط cbXRP، v0.38، کلاس شواهد، رخدادها، محدودیت‌ها و نقشه‌راه |
| پروندهٔ فارسی و انگلیسی نهایی تا ۲۷ مرداد | Opportunity Census، Capture چندبازاره، Gate چرخشی، Freeze و تصمیم‌های Provenance |
| مستندات روز ۲۸ مرداد | Final Technical Gate، Evidence Freezer، Handoff و رخدادهای Disk/Swap و Provenance |
| مستندات تا ۲۹ مرداد | Integrated Candidate، Shadow رخدادمحور، Health دقیق و تفسیر Route اجرا‌نشده |
| مستندات روز ۳۰ مرداد | Runtime مربوط به L0 Funded Shadow و اصلاح محیط اجرا |
| مستندات روز ۳۱ مرداد | آماده‌سازی تصمیم کنترل‌شدهٔ L1 و بازبینی دستی |
| خلاصه تا ۱ شهریور | معماری تجمیعی، ریسک Provider، مسیر L0/L1 و گیت‌های بعدی |
| شواهد روزهای بعد در خط G5 | وضعیت G5B2، G5B3 و G5C به‌عنوان Update پس از برش تاریخی |

## روش

۱. استخراج واقعیت‌ها و نتایج تاریخ‌دار؛
۲. تعیین کلاس شواهد؛
۳. حذف کد، شناسه‌های دقیق، پارامترهای حساس و جزئیات قابل‌بازسازی؛
۴. تطبیق تاریخ‌های تکراری یا اصلاح‌شده؛
۵. انتشار فقط نتیجهٔ عمومی و محدودیت آن.

مخزن عمومی نباید به‌عنوان کپی Byte-for-byte آرشیو خصوصی مهندسی تلقی شود.
