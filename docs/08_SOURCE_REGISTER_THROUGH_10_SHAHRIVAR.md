## Method

1. Extract the dated facts and outcomes.
2. Label the evidence class.
3. Remove code, exact identifiers, sensitive parameters, and reconstructable details.
4. Reconcile duplicate or corrected dates.
5. Publish only the public conclusion and its limitation.

The public repository should never be treated as a byte-for-byte copy of the private engineering archive.
